# Coast Easy Autos Inventory App

## Local setup
1. Install Node.js.
2. Open this folder in VS Code or terminal.
3. Create a file named `.env` and add:

VITE_SUPABASE_URL=https://rqxwivuaiqmkqohokysx.supabase.co
VITE_SUPABASE_ANON_KEY=your_publishable_key_here

4. Run:

npm install
npm run dev

## Vercel setup
1. Upload this project to GitHub.
2. Import the GitHub project into Vercel.
3. Add Environment Variables:
   - VITE_SUPABASE_URL
   - VITE_SUPABASE_ANON_KEY
4. Deploy.

## Phone use
Open the Vercel link on your phone.
- iPhone: Safari > Share > Add to Home Screen
- Android: Chrome > three dots > Add to Home Screen
